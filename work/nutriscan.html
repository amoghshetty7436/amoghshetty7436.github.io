NutriScan: deficiencies you can see

Many nutritional deficiencies leave visible signs in the eyes, nails and teeth long before a blood test is ordered. NutriScan classifies those signs from phone photos and suggests what to do next.

BuiltJan 2025
ContextIBM Hackathon, represented the college at state level
StackMobileNetV2, IBM Vision Models, IBM Watson ML, Cloudant, Django, IBM LLMs
95.3%accuracy across 12 deficiency categories
3image types: eye, nail, dental
Liveinference on IBM Watson Machine Learning
photo: eye · nail · teeth→MobileNetV2 + IBM Vision→deficiency class→IBM LLM→personal recommendations

How it works

A multimodal vision system built on MobileNetV2 and IBM Vision Models classifies each photo into one of 12 deficiency categories. Inference runs on IBM Watson Machine Learning with results stored in Cloudant. A Django web app ties it together and calls IBM's LLMs for a plain-language assessment and recommendations.

About the repo. GitHub holds the earlier local prototype, a smaller MobileNetV2 model that overfit on 661 images. That result is why the delivered system moved to IBM's vision models.
